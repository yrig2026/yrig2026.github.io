YRIG WEBSITE — PUBLISHING GUIDE

This is a responsive static website for Youth Rising Investment Group (YRIG), based on the supplied YRIG Website & Management System project plan.

Files:
- index.html — main website
- assets/style.css — responsive design
- assets/script.js — mobile navigation
- robots.txt and sitemap.xml — basic search-engine files

PUBLISH:
1. Register/connect yrig.org with your hosting provider.
2. Upload the contents of this folder to the hosting public_html/root folder.
3. Make sure index.html is in the web root.
4. Enable HTTPS/SSL.
5. Test the contact form and replace the mailto form with your hosting/form provider if needed.

IMPORTANT:
The supplied project plan describes a future member portal and admin system (registration, secure login, dashboards, savings, investments, loans, voting, transactions, QR cards, notifications, admin management, reports, audit logs and finance modules). Those require a backend/database and are not represented as fake working features in this static launch version.

Before public launch, verify the listed phone numbers, payment details, email address, organization registration information, privacy policy, terms, and any financial/loan compliance requirements.
